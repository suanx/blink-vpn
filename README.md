# Blink VPN

Blink VPN — fast, free VPN client. Flutter app, Android first, Windows next.

> **Status: scaffold only (v0.1.0).** The UI, navigation, node list and speed
> test work, but `VpnService.connect()` is a **simulated placeholder** — it
> does NOT create a real VPN tunnel yet. Real traffic routing needs the
> sing-box / VLESS core integration (see "Next steps" below). Do not present
> this build as a working VPN.

## What is in this repo

- `lib/main.dart` — app entry, single full-screen home page (no bottom navigation)
- `lib/theme/app_theme.dart` — light theme only, small fonts, blue/cyan, no purple
- `lib/models/node.dart` — node model
- `lib/services/vpn_service.dart` — node list (Hong Kong, Japan, Singapore,
  United States), simulated connect/disconnect, HTTP speed test against
  `speed.cloudflare.com`
- `lib/screens/` — home_screen (Psiphon-style full-screen page: brand top-left,
  blue→cyan gradient orb, region pill, large status line, floating pill control
  bar; Nodes reached via the region pill, Speed via the settings gear),
  nodes_screen (node list, tapping a node selects it and returns home),
  speed_screen (speed test)
- `.github/workflows/build-apk.yml` — builds a debug APK on every push to
  `main` and uploads it as an artifact

All Dart code was generated by Groq `qwen/qwen3.8-27b` (free tier) and reviewed
by hand before use. The home-screen redesign (2026-11-25) was drafted by Groq
`qwen/qwen3.8-27b`; Kilo `nvidia/nemotron-3-nano-omni-30b-a3b-reasoning:free`

## Build the APK (GitHub Actions — no local Flutter needed)

1. Push to `main` (or trigger the workflow manually from the Actions tab).
2. Wait for the "Build APK" run to finish.
3. Download the `blink-vpn-debug-apk` artifact from the run page.
4. Install the APK directly on an Android phone (direct APK distribution,
   no Google Play yet).

## Build locally (optional)

Requires Flutter 3.24+:

```sh
flutter pub get
flutter analyze
flutter build apk --debug
```
