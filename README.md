# Blink VPN

Blink VPN — fast, free VPN client. Flutter app, Android first, Windows next.

> **Status: scaffold + Psiphon emergency mode (Phase 1, proxy mode only).**
> The UI, navigation, node list and speed test work, but `VpnService.connect()`
> is a **simulated placeholder** — it does NOT create a real VPN tunnel yet.
> Psiphon emergency mode (2026-11-25) is proxy mode only: a local SOCKS5/HTTP
> proxy on the phone, in-app use only, NOT device-wide VPN. It also needs
> Blink's own SponsorId / PropagationChannelId from Psiphon Inc. — the
> config currently holds placeholders and the tunnel will fail to start
> until those are filled in. Do not present this build as a working VPN.

## What is in this repo

- `lib/main.dart` — app entry, bottom navigation (Home / Nodes / Speed)
- `lib/theme/app_theme.dart` — light theme, small fonts, blue/cyan, no purple;
  dark theme follows the system setting
- `lib/models/node.dart` — node model
- `lib/services/vpn_service.dart` — node list (Hong Kong, Japan, Singapore,
  United States), simulated connect/disconnect, HTTP speed test against
  `speed.cloudflare.com`
- `lib/screens/` — home_screen (one-tap connect), nodes_screen (node list),
  speed_screen (speed test)
- `.github/workflows/build-apk.yml` — builds a debug APK on every push to
  `main` and uploads it as an artifact

All Dart code was generated by Groq `qwen/qwen3.8-27b` (free tier) and reviewed
by hand before use. See the commit history / generation log for details.

## Build the APK (GitHub Actions — no local Flutter needed)

1. Push to `main` (or trigger the workflow manually from the Actions tab).
2. Wait for the "Build APK" run to finish.
3. Download the `blink-vpn-debug-apk` artifact from the run page.
4. Install the APK directly on an Android phone (direct APK distribution,
   no Google Play yet).

## Build locally (optional)

Requires Flutter 3.24+:

```sh
flutter pub get
flutter analyze
flutter build apk --debug
```
